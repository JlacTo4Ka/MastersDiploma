# Выпускная квалификационная работа магистра

## Нейросетевые алгоритмы решения обратной задачи теплообмена летательного аппарата: восстановление нестационарного теплового потока по температурным измерениям

**Студент:** А. В. Павловский  
**Группа:** М8О-207СВ-25  
**Научный руководитель:** Д. Л. Ревизников

---

Репозиторий будет содержать все основные материалы ВКР: исходный код, отчет, презентацию и материалы вычислительных экспериментов.

**Цель работы** — разработка и исследование физически-информированного нейросетевого алгоритма решения обратной задачи теплообмена летательного аппарата, связанной с восстановлением нестационарного теплового потока по температурным измерениям.

Для достижения указанной цели поставлены следующие задачи:

1. исследовать существующие методы решения обратных задач теплообмена и физически-информированные нейронные сети (PINN);
2. сформулировать математическую постановку прямой и обратной задач теплообмена;
3. реализовать прямую модель для расчета температурного поля при заданном тепловом воздействии;
4. разработать и реализовать PINN для восстановления неизвестного теплового потока по температурным данным;
5. подготовить данные для обучения, тестирования и проведения вычислительных экспериментов;
6. исследовать точность и устойчивость разработанного подхода и провести сравнение с базовым методом.

В работе планируется использовать следующие инструменты:

1. язык программирования Python;
2. библиотеку PyTorch для построения и обучения PINN и автоматического дифференцирования;
3. библиотеки NumPy и SciPy для численного моделирования и обработки результатов;
4. библиотеку Matplotlib для визуализации результатов вычислительных экспериментов;
5. среду Jupyter Notebook для исследовательских расчетов и прототипирования.

В качестве ожидаемых результатов работы можно выделить:

1. математическую постановку прямой и обратной задач теплообмена;
2. программную реализацию прямой модели теплообмена;
3. реализованный PINN-алгоритм восстановления нестационарного теплового потока по температурным измерениям;
4. набор данных и методику проведения вычислительных экспериментов;
5. количественную оценку точности и устойчивости разработанного метода;
6. сравнение результатов PINN с базовым методом и определение границ применимости подхода.
